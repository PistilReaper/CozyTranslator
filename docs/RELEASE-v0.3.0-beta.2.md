# CozyTranslator v0.3.0-beta.2 · 右键取词修复

## 更新

- 右键模式统一通过复制取词：按住左键选中文字，再点右键，软件发送一次 Ctrl+C 并读取本次复制的内容。
- 修复旧内核浏览器能复制文字却无法取词的问题，已在 Chrome 152 和 360 极速 X 22.3 验证单词、句段、焦点及右键菜单。
- 仅接收原应用本次产生的新剪贴板文本；复制失败时显示提示，不翻译旧内容或其他程序写入的文本。
- 英文 README 默认展示，提供中文切换；源码与发行包排除内部工作文档。

## 使用

下载 `CozyTranslator-v0.3.0-beta.2-win-x64.zip`，解压后运行 `CozyTranslator.exe`。先退出正在运行的旧版本；模型、密钥和外观设置保留。

设置 → 翻译触发 → **模式 2 · 右键模式**。按住左键选中文字，不松手，再用中指点右键。单词进入查词，句段进入翻译。

**右键取词会把剪贴板更新为选中的原文。** 普通右键菜单和原文焦点保留。复制即翻译、右键模式和仅手动仍互斥。

## 支持范围

原应用必须允许正常复制文本。扫描图片、禁止复制的内容、高权限应用或拦截复制快捷键的环境不保证支持。当前为未签名的 Windows x64 自包含便携包，无需另装 .NET。

附件包含 Windows 便携包、源码包和 SHA256 校验文件。MIT 开源。
