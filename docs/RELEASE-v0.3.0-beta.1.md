# CozyTranslator v0.3.0-beta.1 · 首次公测

轻量 Windows 桌面 LLM 翻译与查词工具，使用自己的 API Key。

## 下载与使用

下载 `CozyTranslator-v0.3.0-beta.1-win-x64.zip`，解压后运行 `CozyTranslator.exe`。
Windows x64 自包含版，无需另装 .NET。旧版用户先在托盘退出旧程序；原有模型、密钥和外观设置保留。

## 新增：模式 2 · 右键模式

1. 设置 → 翻译触发 → **模式 2 · 右键模式** → 保存设置。
2. 在文档中按住鼠标左键选中文字。
3. **左键保持按下，用中指点击右键**，即可触发；随后正常松开左键。

单词进入词典，句段进入翻译。直接读取选区，不复制文本到剪贴板，不抢原文焦点。普通右键仍显示原应用的菜单。
可随时在设置或托盘切回“模式 1 · 复制即翻译”或“仅手动”。

## 已包含

- OpenAI 兼容接口（如 DeepSeek）、Claude 和 Gemini 原生协议；自己的 API Key、模型与系统提示词。
- 学术到口语五档风格、流式翻译、英美音标和本地单词朗读。
- Markdown 标题、强调、列表、引用、代码、表格和常见 LaTeX 公式。
- 可调字号、系统/浅色/深色主题、悬浮球、置顶、任务栏与托盘、全局快捷键。
- 密钥通过 Windows DPAPI 在本机加密保存；MIT 开源。

## 公测边界

- 右键模式依赖原应用提供 Windows UI Automation 文本选区。扫描图片、画布式阅读器、不提供文本选区的控件和高权限应用不保证支持；未读取到文本时不会发送模型请求。
- 已用独立文档进程验证真实双键输入、查词/句译、菜单、焦点与剪贴板。尚未逐一认证所有 Word/PDF/浏览器版本。
- 公式采用轻量 LaTeX 子集，`aligned`、自定义宏等未支持语法显示源码。
- 当前便携包未签名。本轮协议测试使用响应夹具，未使用真实云端账户验证每家模型。

反馈请附 Windows 版本、原应用及版本、复现步骤；不要在 Issue 中粘贴 API Key 或敏感原文。

附件包含 Windows 便携包、源码包和 SHA256 校验文件。
