# CozyTranslator v0.3.0-beta.1

## 目标

在阅读论文、技术资料与日常写作时，通过桌面小窗随手翻译；英文单词则以传统词典的方式查看释义、音标和发音。

## 已确认决策

| 事项 | 决策 |
|---|---|
| 平台 | Windows x64 原生桌面应用 |
| 技术 | C#、WPF、.NET 10，自包含 ZIP |
| 主要入口 | 外部复制后自动翻译；悬浮球和快捷键保留手动查询 |
| 语言 | 中英互译，兼顾科研与日常 |
| API | OpenAI 兼容、Claude 原生、Gemini 原生；用户填写地址、Key、模型 |
| 翻译窗口 | 上下对照、可编辑原文、流式译文 |
| 提示词 | 内置可编辑的翻译系统提示词 |
| 场景 | 学术、专业、通用、自然、口语五档；松手后按新档位重译 |
| 查词 | 自动英文单词识别；精简音标、词性、常见释义 |
| 发音 | 音标文字和 Windows 本地英文朗读 |
| 主题 | 跟随系统、浅色、深色；字号 16–24 |
| 名称 | CozyTranslator |
| 视觉 | 参考苹果与 Anthropic：克制留白、暖纸白、陶土强调、无衬线排版 |

## 视觉规范

- 浅色：纸白 `#F8F6F1`、表面 `#FFFEFB`、墨色 `#2D2C29`、陶土 `#B9674D`。
- 深色：炭色 `#242522`、表面 `#2E2F2B`、米白 `#EDE8DF`、浅陶土 `#D79476`。
- 窗体圆角 12 DIP，输入区 12 DIP，主操作按钮 9 DIP；边界与阴影保持轻薄。
- 中英文使用无衬线系统字体；Cozy 与 Translator 同级。正文默认 18，模块文字默认 14。
- 窗口保持用户设定尺寸，切换模式不自动改高度；模式区按内容计算高度。
- 原文区提供轻边框，译文区以排版和留白组织内容。

## 交互完整性

每次新请求取消旧请求；查询代次保证旧响应不能更新新界面。窗口收起保留会话，退出释放资源。同一输入再次唤出展示当前结果；复制本应用结果后唤出也保持当前结果。

查词通过独立提示词请求 JSON，经字段校验后显示。不能识别、音标缺失、权限错误、限流、响应中断及空内容都有明确状态。句段翻译中的文字只作为输入数据，不执行其中包含的指令。

## 数据与验证

设置保存在用户本地应用数据目录，Key 使用 DPAPI 加密。翻译文本只保留于当前会话，复制后自动查询，文本直接发送到所配置的模型服务；自身复制、设置期间和暂停状态不自动查询。

核心协议与状态测试、Windows 实机检查和资源测量见根目录 `VALIDATION.md`。两份 HTML 参考使用测试夹具驱动的真实 WPF 渲染图片。

## v0.2.0 科研译文

原生渲染 Markdown 标题、强调、列表、引用、代码与简单表格；本地排版四种定界符的常见 LaTeX 公式。公式跟随字号、主题，宽公式可横向滚动。复制按钮与全选保留原始 Markdown，局部复制保留所选公式源码。流式更新复用公式，保持阅读位置。采用轻量 LaTeX 子集，具体边界见 README 和 VALIDATION。

## v0.3.0-beta.1 右键选区与公测

翻译触发三选一：复制即翻译、按住左键选区时点击右键、仅手动。右键手势直接读取 Windows UI Automation 选区，不修改剪贴板；显示或恢复结果窗口但保持原文焦点。正常右键菜单保留。源码采用 MIT，GitHub Release 标记为公测预发布。
